# Google Merchant Feed - Google Shopping Expert

A powerful PrestaShop module for generating and managing product feeds for
Google Merchant Center and Google Shopping.

The module helps PrestaShop store owners export product information in a
Google Merchant-compatible feed format and configure product data according
to Google Shopping requirements.

## Features

- Generate Google Merchant Center product feeds
- Support Google Shopping product listings
- Configure product feed settings from the PrestaShop Back Office
- Include product title and description
- Export product prices
- Export product availability and stock status
- Export product condition
- Export product images
- Support additional product images
- Configure product categories
- Configure Google Product Category
- Configure product identifiers
- Configure `identifier_exists`
- Support brand and manufacturer information
- Support SKU / reference / product IDs
- Configure product dimensions
- Configure shipping information
- Configure tax-related information
- Support multiple currencies
- Configure product ID generation
- Generate feed URLs for Google Merchant Center
- Support feed customization
- PrestaShop Back Office configuration
- Compatible with Composer-based projects

## Requirements

Before installing the module, make sure your environment meets the following
requirements:

- PrestaShop 1.7.x or higher
- PHP version compatible with your PrestaShop installation
- MySQL / MariaDB database
- PHP extensions required by your PrestaShop version
- Composer (if required by the module configuration)

> Make sure the module version is compatible with your installed PrestaShop
> version before installation.

## Installation

### Method 1: PrestaShop Back Office

1. Download the module ZIP package.
2. Log in to your PrestaShop Back Office.
3. Go to:

   `Modules > Module Manager`

4. Click **Upload a module**.
5. Select the module ZIP file.
6. Upload and install the module.
7. Open the module configuration page.
8. Configure your Google Merchant Feed settings.
